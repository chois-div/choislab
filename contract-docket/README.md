# 계약 파일

계약 초안 작성부터 전자 서명 요청과 회신 확인까지 이어지는 Next.js MVP입니다.

## 시작하기

```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 계약 데이터와 PDF 파일은 `.local-data/`에 저장됩니다.

## 제공 기능

- 계약 내용을 직접 작성하거나 15MB 이하 PDF를 업로드하고 초안을 수정
- 마우스·터치로 서명을 그리거나 PNG/JPG 서명 이미지를 삽입
- 계약 본문 또는 PDF 미리보기와 참여자·진행 기록 확인
- 설정한 SMTP 계정으로 14일 만료 서명 링크를 실제 발송
- 수신자가 링크에서 계약서를 확인하고 서명하거나 거절 회신
- 발신자 대시보드의 상태 변경과 SMTP 회신 알림

## 레퍼런스 분석

[모두싸인 공개 홈페이지](https://modusign.co.kr/)는 문서 작성·발송·서명·보관을 잇는 전자계약 흐름을 핵심 메시지로 제시합니다. 이 MVP는 요청하신 작성→날인→미리보기→이메일 링크 발송→회신을 문서 중심 화면과 수신자 서명 화면으로 구현했습니다. 브랜드 자산이나 화면을 복제하지 않았으며, 공개 홈페이지의 보안·법적 효력 메시지를 이 MVP의 보증으로 가져오지 않았습니다.

실제 이메일을 발송하려면 `.env.local`에 SMTP 서버 정보를 설정하고 `APP_URL`을 지정해야 합니다. 일반적으로 SMTP 587 포트는 `SMTP_SECURE=false`, 465 포트는 `SMTP_SECURE=true`를 사용합니다. 외부 공개 주소는 HTTPS여야 합니다. `MAIL_FROM`은 SMTP 계정에서 발신이 허용된 주소를 사용하세요. SMTP 설정이 없거나 발송이 실패하면 계약은 발송 완료로 표시되지 않습니다. 서명 완료 후 발신자 알림 메일도 전송합니다.

## 범위와 보안

이 프로젝트는 로컬 단일 사용자 MVP입니다. 로그인/조직 권한, 외부 데이터베이스·파일 저장소, 수신자 본인 확인, 감사 추적 인증서, 법률 효력 보증은 구현되어 있지 않습니다. 현재 대시보드 API와 로컬 파일 저장소는 사용자 인증 없이 동작하므로 공개 서버에 배포하지 마세요. 실제 운영 전에 인증/권한 검사, 암호화된 영속 저장소, 접근·회신 감사 로그, 백업·보존 정책, 보안 및 관할 법률 검토가 필요합니다.

PDF에 서명 이미지의 좌표를 지정하거나 원본 PDF에 합성하지는 않습니다. 업로드한 PDF는 원본 그대로 보관하고, 서명 이미지·서명자 이름·회신 시각을 계약 기록에 저장합니다. 본문 입력 계약은 미리보기에서 서명을 함께 확인할 수 있습니다.
